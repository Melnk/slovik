# Словик

Friendly-приложение для изучения слов с помощью карточек. Вставьте сразу весь список в формате:

```text
journey - путешествие
cozy - уютный
wander - бродить
```

Словик автоматически превратит каждую строку в отдельную карточку.

## Возможности

- массовый импорт пар `слово - перевод`;
- несколько независимых наборов;
- карточки с переворотом и оценкой ответа;
- умное повторение всей колоды в случайном порядке;
- автоматический возврат сложных слов в очередь;
- секундная подсказка с переводом при смене карточки;
- режим в обе стороны: EN → RU и RU → EN;
- перемешивание, прогресс и результат тренировки;
- управление пробелом и стрелками;
- сохранение наборов в браузере без регистрации;
- адаптивный интерфейс для компьютера и телефона.

## Запуск локально

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Технологии

React 19, TypeScript, vinext, Vite и Cloudflare Workers.
