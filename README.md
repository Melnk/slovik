# Словик

Friendly-приложение для изучения слов с помощью карточек. Вставьте сразу весь список в формате:

```text
journey - путешествие
cozy - уютный
wander - бродить
```

Словик автоматически превратит каждую строку в отдельную карточку.

## Начать без установки

1. [Откройте Словик](https://slovik.olgorgpt.chatgpt.site/) в браузере.
2. Вставьте слова и нажмите «Создать карточки».

Чтобы Словик выглядел на телефоне как обычное приложение:

- на iPhone или iPad откройте сайт в Safari, нажмите «Поделиться» → «На экран Домой»;
- на Android откройте сайт в Chrome, нажмите меню ⋮ → «Добавить на главный экран».

Преподаватель может нажать ⧉ у готового набора, отправить скопированный список ученикам в чат, а ученики — вставить его в Словик. Результаты каждого ученика сохраняются только на его устройстве.

## Возможности

- массовый импорт пар `слово - перевод`;
- несколько независимых наборов;
- копирование любого набора в исходный формат `слово — перевод` для переноса или резервной копии;
- переименование сохранённых наборов;
- карточки с переворотом и оценкой ответа;
- случайный порядок карточек в каждой новой тренировке;
- повторение по 5 слов: до 3 сложных и случайные слова из колоды;
- счётчик сложных слов в каждом наборе;
- автоматический возврат сложных слов в очередь;
- автосохранение после каждого шага и продолжение незавершённого подхода;
- режим в обе стороны: EN → RU и RU → EN;
- пошаговая подсказка скрытого ответа: каждое нажатие открывает ещё одну букву, но не ответ целиком;
- возможность отложить закрытую карточку в конец подхода и попробовать вспомнить её позже;
- озвучивание слова или перевода на текущей стороне карточки;
- перемешивание, прогресс и результат тренировки;
- управление пробелом и стрелками;
- сохранение наборов в браузере без регистрации;
- адаптивный интерфейс для компьютера и телефона.

## Запуск проекта для разработчиков

Нужен [Node.js 22.13 или новее](https://nodejs.org/).

1. Скачайте проект:

   ```bash
   git clone https://github.com/Melnk/slovik.git
   cd slovik
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите приложение:

   ```bash
   npm run dev
   ```

Откройте [http://localhost:3000](http://localhost:3000) в браузере. Для остановки нажмите `Ctrl+C` в терминале.

## Проверка перед публикацией

Проверка production-сборки:

```bash
npm run build
```
