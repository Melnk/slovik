# Словик

Словик — приложение для изучения слов по собственным спискам. Создайте набор, вспоминайте ответы по карточкам и возвращайтесь к словам, которым подошёл срок повторения. Регистрация не нужна: библиотека и прогресс хранятся в браузере на текущем устройстве.

## Продуктовое состояние v0.2

Это локальная версия для проверки полного учебного сценария: импорт → тренировка → повторение по расписанию → редактирование → резервная копия и перенос. Её можно использовать для пилота с учениками и преподавателями. Соответствие рынку, удержание пользователей и эффективность выбранных интервалов ещё нужно проверить на реальном использовании; наличие функций само по себе этого не подтверждает.

В этой версии есть:

- экран «На сегодня» с продолжением незавершённого подхода, карточками к повторению, новыми словами и результатами за день;
- расписание повторения отдельно для каждой карточки;
- создание наборов из текста, поиск по названию и содержимому, просмотр и копирование слов;
- редактор названия, слов и переводов с добавлением и удалением пар;
- полная JSON-копия библиотеки с учебным прогрессом и безопасное добавление наборов из неё;
- обработка недоступного или повреждённого хранилища и конфликтов между вкладками;
- адаптивная тренировка, управление с клавиатуры, подсказки и браузерное озвучивание.

Аккаунтов, облачной синхронизации и подтверждённого автономного режима в текущем учебном сценарии нет. Добавление значка сайта на главный экран телефона не гарантирует работу без сети.

## Как учиться

1. Откройте приложение и попробуйте демонстрационный набор либо нажмите «Новый набор».
2. Вставьте список: одна пара на строку, между словом и переводом — тире с пробелами или табуляция. Табуляция позволяет вставить две колонки из таблицы.

   ```text
   journey - путешествие
   cozy - уютный
   wander - бродить
   ```

3. Проверьте количество распознанных пар. Пропущенные и повторяющиеся строки можно раскрыть, скопировать и исправить.
4. Во время тренировки сначала вспомните ответ, затем переверните карточку и отметьте «Вспомнил!» или «Пока не помню».
5. Возвращайтесь на экран «На сегодня»: сначала повторяйте слова по сроку, затем добавляйте новые. Рекомендованный короткий подход содержит до 10 карточек одного набора.

Преподаватель может скопировать список из набора и передать его ученику. Ученику нужно создать собственный набор из этого текста; результаты учителя и ученика остаются раздельными.

### Как работает расписание

После ошибки следующая дата повторения — через **10 минут**, а последовательность успешных повторений начинается заново. Если правильный ответ дан в срок или позже, интервалы последовательно составляют **1, 3, 7, 14, 30 и 60 дней**. После достижения 60 дней этот интервал повторяется.

Дополнительный правильный ответ до назначенного срока не увеличивает интервал и не отодвигает повторение. Ошибка при ранней тренировке всё равно назначает возврат через 10 минут. В режиме закрепления забытое слово может также вернуться в текущую очередь — это отдельный механизм тренировки.

Это простой прозрачный алгоритм с фиксированными интервалами. Он не реализует FSRS, не подбирает расписание персонально и не гарантирует запоминание. Направления карточки используют одно расписание.

### Что означают результаты

Последний процент у набора — результат последнего завершённого подхода, а не доля окончательно выученных слов. Оценку ответа выставляет сам пользователь.

Дневные результаты и серия учебных дней считаются по истории завершённых подходов, записанной начиная с v0.2. Для старых наборов общий счётчик подходов сохраняется, но прежние даты не восстанавливаются и задним числом не рисуются. Дни определяются по часовому поясу браузера. Незавершённый подход не попадает в дневной итог до завершения.

### Дополнительные режимы

- весь набор в случайном или исходном порядке, быстрый подход на 10 слов;
- короткое закрепление, тренировка сложных слов и повтор ошибок последнего подхода;
- обучение в обе стороны, повтор тех же слов в обратном направлении;
- перемешивание оставшихся карточек и откладывание текущей на потом;
- постепенное открытие букв ответа, обычное и медленное озвучивание, автоозвучивание;
- просмотр набора со скрытыми словами или переводами, раскрытие ответов по одному;
- копирование пары, всего набора или списка ошибок.

Озвучивание зависит от поддержки браузера и доступных на устройстве голосов. Для английского и русского выбираются соответствующие языки; качество и доступность для других языков не гарантируются.

### Клавиатура

| Клавиша | Действие |
| --- | --- |
| `Esc` | Вернуться к наборам с сохранением подхода |
| `Пробел` | Перевернуть карточку |
| `←` / `→` | После переворота: «Пока не помню» / «Вспомнил!» |
| `H` / `Shift+H` | Открыть следующую букву / скрыть подсказку |
| `L` / `Shift+L` | Озвучить скрытый ответ / произнести медленно |
| `P` / `Shift+P` | Озвучить текущую сторону / произнести медленно |
| `B` / `Shift+B` | После переворота озвучить пару / произнести медленно |
| `A` | Переключить автоозвучивание |
| `R` | Отложить закрытую карточку |
| `S` | Перемешать оставшиеся карточки |
| `D` | Поменять направление |
| `C` | Скопировать раскрытую пару |

## Редактирование и перенос

Кнопка редактирования у набора открывает название и список пар. Можно исправлять обе стороны, добавлять новые карточки и удалять лишние. Нельзя сохранить пустую сторону или одинаковую пару дважды. Прогресс неизменённых карточек сохраняется; новые карточки начинают обучение без истории.

В библиотеке откройте «Резервная копия и перенос»:

1. «Скачать резервную копию» создаёт JSON-файл с наборами, карточками, ошибками, расписанием и записанной историей завершённых подходов.
2. На другом устройстве выберите этот файл. Приложение проверит формат и покажет количество наборов и карточек.
3. Нажмите «Добавить наборы». Текущая библиотека остаётся на месте; при совпадении идентификатора набора создаётся отдельная копия. Повторный импорт может добавить дубликаты.

**Активный незавершённый подход в JSON-копию не входит.** Его можно продолжить только в исходном браузере, пока сохранённые данные доступны. Копирование обычного списка слов переносит только текст, без результатов и расписания.

Лимиты: JSON-файл до 10 МБ, до 500 наборов и 50 000 карточек в библиотеке, до 2 000 карточек в наборе, название до 120 символов, каждая сторона карточки до 2 000 символов. Реальный доступный объём `localStorage` зависит от браузера и может оказаться меньше этих ограничений.

### Сохранность данных

Автосохранение использует локальное хранилище браузера. Очистка данных сайта, приватный режим, смена браузера или адреса приложения могут сделать библиотеку недоступной. Локальный адрес и опубликованный сайт имеют разные хранилища. Регулярно скачивайте резервную копию и проверяйте её восстановление.

Если приложение сообщает об ошибке сохранения, выгрузите JSON-копию текущих данных. При конфликте вкладок сначала сохраните нужную копию, затем загрузите изменения из другой вкладки. Не очищайте данные сайта до сохранения нужных наборов. JSON содержит слова и результаты в открытом виде — передавайте файл только тем, кому доверяете.

## Запуск из репозитория

Нужен [Node.js 22.13 или новее](https://nodejs.org/).

```bash
git clone https://github.com/Melnk/slovik.git
cd slovik
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для остановки нажмите `Ctrl+C` в терминале. Для запуска собранной версии используйте `npm run build`, затем `npm start`.

## Проверка релиза

```bash
npm run lint
npm run typecheck
npm test
```

`npm test` собирает production-версию и запускает `node --test tests/*.test.mjs`: проверки серверного HTML, формата библиотеки, резервных копий, сохранения и алгоритма повторений. GitHub Actions запускает эти проверки при изменениях репозитория. Эти тесты не заменяют проверку поведения приложения в настоящем браузере.

Перед публикацией также пройдите в браузере: создание и исправление набора → оценка ответов → продолжение после перезагрузки → скачивание и восстановление копии → конфликт двух вкладок. Проверьте повреждённое/недоступное хранилище, длинные фразы, работу клавиатуры и экран телефона 375×667. Полный автоматизированный набор браузерных сценариев остаётся следующим этапом.

## Следующие продуктовые приоритеты

| Приоритет | Работа | Критерий готовности |
| --- | --- | --- |
| 1 | Пилот с учениками и преподавателями | Согласованы аудитория и учебная задача; проведены реальные занятия; зафиксированы проблемы первого запуска и причины возврата/отказа. Метрики активации, повторного использования и ошибок заранее определены; сбор событий запускается только с понятным согласием и возможностью отказа. Результаты публикуются с реальным объёмом выборки. |
| 2 | Автоматизация браузерных проверок | В CI на реальном браузере проходят создание, редактирование, повторение, reload/resume, backup/restore и конфликт вкладок; есть проверки маленького экрана и клавиатуры. Сейчас автоматизированы Node/SSR-проверки, browser e2e ещё предстоит добавить. |
| 3 | Надёжный опубликованный сервис | Развёртывание воспроизводимо, проверены домен и HTTPS, описаны обновление и откат; production smoke-проверка подтверждает сохранение и восстановление пользовательских данных. Указаны канал поддержки и порядок обработки проблем с данными. |
| 4 | Аккаунт и синхронизация, если пилот подтвердит потребность в нескольких устройствах | Работают hosted-аутентификация, разграничение доступа и синхронизация с разрешением конфликтов. Проверены два устройства, потеря сети, восстановление и удаление аккаунта; согласованы политика хранения и согласие пользователя. До этого облачную синхронизацию обещать нельзя. |
| 5 | Автономное PWA после проверки качества | Manifest и service worker проверены на поддерживаемых браузерах; обучение, сохранение и последующий запуск работают без сети; обновление приложения не теряет библиотеку. Пройдены проверки iOS/Android, ограничений storage и восстановления копии. |
| 6 | Дальнейшее улучшение учебной модели и импорта | По наблюдениям пилота выбраны нужные форматы импорта и критерии качества. На отложенной проверке измерено вспоминание слов и нагрузка на ученика; изменения расписания сравниваются с текущим подходом на согласованных данных. |

Нельзя честно объявить продукт готовым к рынку до подтверждения реальной пользы и возврата пользователей в выбранной аудитории, проверки сохранности данных и завершения эксплуатационных сценариев. Платежи, AI-функции и расширение каталога стоит добавлять после проверки спроса, а не использовать как доказательство готовности.

## Ориентиры для развития

Проверено по официальной документации 2 ноября 2026 года. Это ориентиры ожидаемых сценариев, а не подтверждение эффективности Словика или совместимости форматов:

- [Anki: импорт текстовых файлов](https://docs.ankiweb.net/manual/importing/text-files) — поддержка разделителей, предпросмотр и правила обработки повторов задают полезный ориентир для развития импорта.
- [Quizlet: обучение с интервальным повторением](https://help.quizlet.com/hc/en-ca/articles/48324742264077-Studying-with-Spaced-Repetition) — оценка вспоминания и следующая дата повторения помогают пользователю понимать ежедневную работу. Словик использует собственную простую последовательность фиксированных интервалов, описанную выше.

## Технологии

React 19, TypeScript, vinext, Vite и Cloudflare Workers. Учебный интерфейс хранит данные в браузере; наличие серверного каркаса в репозитории не означает включённую облачную синхронизацию.
